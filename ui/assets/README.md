# Optional Vantasm visual assets

The public core deliberately does not depend on assets copied from a developer's private device state.

If distributing the branded control-room artwork/video, place the expected files here:

- `masthead-wide.webp`
- `masthead-tall.webp`
- `vantasm-loop-poster.webp`
- `vantasm-loop.mp4`
- `vantasm-crest.webp`
- `repair-skull.webp`
- `ambience-wide.webp`
- `ambience-tall.webp`
- `pillar-left.webp`
- `pillar-right.webp`
- `topology-art.webp`

The UI CSS includes dark-color fallbacks so the operational interface remains usable without optional artwork.
